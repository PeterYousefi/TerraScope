# SiteSignal local architecture

React/TanStack Start in `lovable/` calls a typed FastAPI API in `backend/`. Preserve Three/R3F and GSAP scenes. MapLibre presents source points and candidate polygons; tiles are independent of analysis.

A single bounded local worker polls persisted queued jobs in SQLite through SQLAlchemy. State, execution events and full analysis artifacts survive reloads. Interrupted jobs fail truthfully on startup; this is a single-process local worker, not a production queue. Provider responses use SQLite TTL cache; keys are excluded from cache identifiers/provenance/logging. HTTPX requests have timeouts and conservative retries. Overpass is queried serially and cached.

The Austin-only planner retrieves NLR public operating EV stations, ACS tract population/households/income/commute estimates, official Census TIGERweb tract and Austin place geometries, and OSM destinations/roads. Activated free NLR and Census keys are required; TIGER/OSM need no key. Analysis projects geometries to EPSG:32614 (meters), clips a regular grid to the Austin boundary and aggregates tract population by intersection area (uniform-density assumption). Distances are straight-line meters. No routing time is inferred. Scores use documented configurable weights and cohort min/max normalization; flat dimensions contribute 50. Missing competition data prevents ranking, rather than treating unavailable stations as zero. Missing optional dimensions remain null and are removed from weights with warnings. Sensitivity compares rank under each weight increased 20%.

Each result contains raw normalized source records, retrieval metadata, geographic features, score components, actual events and limitations. Deterministic statistical summaries remain available without AI. OpenAI is disabled unless explicitly enabled and configured; structured tool selection is validated against the supported pipeline. AI explanations can only select candidate/evidence IDs and precomputed observation IDs, preventing invented numeric claims from entering the displayed report. Paid calls are capped and never required for tests.

Local endpoints: frontend 5173, backend 8000, OpenAPI `/docs`. The default workflow is local. An opt-in static frontend target can be served by FastAPI on Azure Free F1; see [Azure hosting](AZURE.md). Authentication and multi-tenant isolation remain outside the current implementation.

## Provider and request bounds

A single worker runs all provider calls serially with a three-connection HTTP pool and at most one retry. NLR uses the documented `limit=all` state query, checks total count completeness, caps state records at 15,000 and filters public operating stations into acquisition bounds. OSM requests parking, supermarkets, malls and major roads with a bounded 45-second query and 128 MiB server memory limit, and rejects partial or over-20,000-object responses. HTTP 429 pauses 30 seconds before retry. Ways/relations without explicit centers use projected source bounding-box representative points; those are not entrances. Roads use their geometry for distances.

Cache TTLs: NLR one day, OSM seven days, Census/TIGER thirty days. Provenance retains original retrieval timestamps on cache hits. SQLite stores full typed investigations and normalized records as JSON artifacts rather than requiring a separate table for every public feature. Stable identifiers link candidate features to these records. A five-job queue and ten-created-jobs-per-hour persisted global limit bound local cost and public-service use. Configuration and health/capabilities have typed OpenAPI contracts.

AI outputs are restricted to supplied evidence observations and ranking IDs, providing bounded evidence synthesis rather than unconstrained prose. Numeric calculations never come from AI. Paid calls require ENABLE_OPENAI, a key and explicitly selected model.
